About Me

My name is Musenga Hope Sichula, and I am a Data Science student at Mulungushi University in the School of Engineering and Technology. I am currently taking ICT251 Web Technologies, which is teaching me how to structure, style and bring web pages to life using HTML, CSS and JavaScript. Outside of web development, my coursework also covers data structures, Java programming and statistics, all of which feed into my long-term goal of building data-driven applications. I enjoy the problem-solving side of programming, and building this personal website has been a practical way to see how the building blocks of the web fit together, from semantic markup to responsive design.

Vehicle & Number-Plate Recognition

A prototype Automatic Number Plate Recognition (ANPR) system for Zambia's Road Transport & Safety Agency (RATSA), using simulated registry data. It tracks vehicles in camera video, reads number plates with OCR, checks each plate against a mock registry and streams alerts to a live dashboard.

  • FastAPI
  • SQLite
